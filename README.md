# 🐄 Cattle Breed Detection System

## 📌 Overview

The **Cattle Breed Detection System** is a Machine Learning and Computer
Vision project that identifies cattle breeds from images.\
This project aims to assist farmers, researchers, and the agriculture
sector by providing a fast and automated way to recognize cattle breeds.

------------------------------------------------------------------------

## 🚀 Features

-   🖼️ Image-based cattle breed classification\
-   🤖 Deep Learning model for prediction\
-   ⚡ Fast and accurate results\
-   📊 Practical real-world application

------------------------------------------------------------------------

## ⚙️ Installation

``` bash
git clone https://github.com/18ankur/cattle-breed-detection.git
cd cattle-breed-detection
pip install -r requirements.txt
```

------------------------------------------------------------------------

## ▶️ Usage

### Train the Model

``` bash
python train_model.py
```

### Run Prediction

``` bash
python app.py
```
